# ⚔️ WIN OR DIE

An extensive, ground-up game development project showcasing raw C++ power. Built strictly with SFML for media handling, leaving all game logic, state machines, and rendering pipelines completely custom-coded.

![C++](https://img.shields.io/badge/Code-33.3K_Lines_in_Main-00599C?style=for-the-badge&logo=c%2B%2B&logoColor=white)
![SFML](https://img.shields.io/badge/Powered_by-SFML-8CC414?style=for-the-badge&logo=sfml&logoColor=white)

### 🧠 Why 33,300 Lines?
Because every pixel's movement, every collision box, and every frame drawn was calculated and optimized manually. This isn't just a game; it's a custom-built game engine tailored for this specific experience.
